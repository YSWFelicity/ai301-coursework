# Rubric: is this reproduction package ready to post?

## Checks

| Check          | Evidence                                                                                                                                                                              | Pass condition                                                                                                                                                                                                                                                                                              | Weight   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| environment    | Repro report's environment record, read against the issue context and repo-facts block; see `references/evidence-guide.md` → Environment                                              | Pass if the report identifies the environment details relevant to reproducing the issue and those details match the issue's target environment, or any relevant differences are explicitly stated.                                                                                                          | required |
| steps          | Reproduction steps in the repro report, read against the issue context; see `references/evidence-guide.md` → Steps                                                                    | Pass if the steps identify the starting state, the actions or commands performed, and the trigger needed to reach the reported result, without requiring a stranger to guess a necessary action.                                                                                                            | required |
| behavior-shown | Artifacts such as output excerpts, logs, screenshots, or recorded observations, read against the behavior described by the issue; see `references/evidence-guide.md` → Behavior shown | Pass if the provided evidence demonstrates the behavior described by the issue, rather than only an adjacent warning, error, or different failure. For a cannot-reproduce result, pass if the evidence instead shows the relevant attempted reproduction completed without the reported behavior occurring. | required |
| honest-outcome | Repro report's stated outcome read against its steps and artifacts; see `references/evidence-guide.md` → Honesty                                                                      | Pass if the stated outcome does not claim more than the evidence supports. A supported successful reproduction passes, and an evidenced cannot-reproduce also passes.                                                                                                                                       | required |
| conventions    | Claim comment and repro report read against the issue context, repo-facts block, and stated contribution or AI-use policies; see `references/evidence-guide.md` → Comms               | Pass if the claim is specific to the issue and promises an investigation rather than a fix, result, or completion date, and the posted or proposed comments follow stated repository communication and disclosure requirements. If no special requirement is stated, its absence does not fail this check.  | required |

## Verdict rule

Accept only if every required check passes. Any failed required check causes a reject verdict. An unclear grade on a required check counts as fail. Preferred checks, if any are added later, do not change the verdict.
