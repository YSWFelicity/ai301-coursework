# Rubric: is this plan ready to post and build from?

## Checks

| Check       | Evidence                                                                                                                                                                        | Pass condition                                                                                                                                                                                                                                                                                                                | Weight   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| diagnosis   | The plan's stated diagnosis read against the reproduction evidence and issue context; see `references/evidence-guide.md` → Diagnosis                                            | Pass if the diagnosis is consistent with the reproduced evidence and gives a plausible explanation for the observed behavior. The root cause does not need to be fully proven before implementation when the plan identifies what still needs verification and does not present unsupported conclusions as established facts. | required |
| scope       | The plan's stated scope, files to change, and exclusions read against the diagnosis and repo-facts block; see `references/evidence-guide.md` → Scope                            | Pass if the proposed change is bounded to the reproduced problem, identifies what will and will not change when relevant, and does not introduce unrelated work or scope creep.                                                                                                                                               | required |
| approach    | The plan's implementation approach and files to touch read against the diagnosis and repository facts; see `references/evidence-guide.md` → Approach                            | Pass if the proposed work addresses the supported cause rather than only an unrelated symptom, and gives enough concrete direction that another contributor could begin implementing it without guessing the essential change.                                                                                                | required |
| test-plan   | The plan's test plan read against the reproduction evidence's steps and observed behavior; see `references/evidence-guide.md` → Test plan                                       | Pass if the proposed test re-runs or appropriately adapts the reproduction and defines an observable result that would distinguish the fixed behavior from the reproduced behavior.                                                                                                                                           | required |
| conventions | The draft plan comment read against the issue thread, repo-facts block, and stated contribution or communication requirements; see `references/evidence-guide.md` → Conventions | Pass if the comment accurately reflects the plan, does not overstate uncertain findings, and follows any stated repository or issue-thread requirements that apply to posting the plan.                                                                                                                                       | required |

## Verdict rule

Accept only if every required check passes. Any failed required check causes a reject verdict. An unclear grade on a required check counts as fail. Preferred checks, if any are added later, do not change the verdict.
